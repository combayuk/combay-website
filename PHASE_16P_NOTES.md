# Phase 16P — Visual CMS exact live canvas and background tools

- Visual CMS now uses the real public page in an iframe as the editing canvas so sections/forms/layout/colours match the live website.
- Left panel only: Pages / Widgets / Style. No right-side crop panel.
- All public pages are listed. Protected/dynamic areas remain visible with no-entry markers where editing is intentionally disabled.
- Admin can click visible text in editable CMS pages and type directly on the page; changes are saved back to CMS content when matching stored CMS text.
- Forms are visible because the canvas is the actual live page.
- Added Replace background tool for hero backgrounds with image upload, URL, flat colours, and gradient library.
- Added support for flat colours and CSS gradients in CMS background fields used by public components.
