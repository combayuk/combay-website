Phase 26.2N — Visual CMS functional website-builder fix

Context:
The user reported that Visual CMS still did not behave like a real website builder and provided strict requirements:
- PC/tablet/mobile and zoom toolbar text must not crop.
- Text style controls must actually work and persist.
- Category management must exist.
- Category icons must be editable from an icon library or uploaded image.
- Widgets must be placed where admin selects/drops them.
- Widgets must persist and appear on the live site.
- Non-editable areas must remain visible/locked.
- CMS preview must remain close to the live website.

Implemented:

1. Device / screen toolbar fix
File: src/components/admin/VisualCmsBuilder.tsx
- Device selector widened.
- Zoom selector widened.
- Added explicit Fit Width (72%) option.
- Kept 60%, 85%, and 100%.
- Added better padding/line-height so PC / Tablet / Mobile and zoom labels display without cropping.

2. Functional text styling
Files:
- src/components/admin/VisualCmsBuilder.tsx
- src/lib/siteContent.ts
- src/components/visual-cms/PublicTextStyleApplier.tsx
- src/app/layout.tsx
- src/app/globals.css

Changes:
- Expanded CmsTextStyle to support:
  - font size
  - font family
  - font weight / bold
  - italic
  - colour
  - alignment left/centre/right
  - line height
  - text type: heading/subheading/body/caption
- Text style inspector now exposes only functional controls.
- Changing a selected text style now applies immediately inside the Visual CMS iframe preview.
- Added PublicTextStyleApplier mounted in root layout so saved CMS text styles apply on the live website after save.
- Added live helper CSS for heading/subheading/caption text-kind styling.

3. Category management
Files:
- src/lib/siteContent.ts
- src/components/admin/VisualCmsBuilder.tsx
- src/components/home/IndustryStrip.tsx
- src/app/page.tsx

Changes:
- Added CmsCategory type and categories[] into CMS content.
- Default categories are seeded from PUBLIC_CATEGORY_GROUPS.
- Categories are normalised and persisted through /api/admin/content.
- Visual CMS now has a Categories tab.
- Admin can:
  - add new category
  - edit name
  - edit slug
  - edit description
  - show/hide category
  - reorder categories up/down
  - delete category
  - select internal icon-library icon
  - upload image/icon
- Homepage IndustryStrip now renders CMS-managed categories from site content.
- Uploaded category images/icons render object-contain inside the existing Combay category icon frame to avoid stretching/layout breakage.

4. Category icon management

5. Widget functionality and persistence
Files:
- src/components/admin/VisualCmsBuilder.tsx
- src/lib/siteContent.ts

Changes:
