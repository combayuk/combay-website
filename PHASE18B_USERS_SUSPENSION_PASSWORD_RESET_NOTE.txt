Phase 18B — Users, suspension, password reset and portal redirect fixes
- Admin users tab added at /admin/users.
- Users table shows registered users, email, phone, role, company/account status and suspension state.
- Admin can suspend/reactivate customer users.
- Suspended users cannot sign in and cannot register again using the same email or phone number.
- Suspension email is sent once when a customer is suspended.
- Customer portal top-bar link now opens customer login even if an admin session exists.
- Forgot password added for both admin and customer login pages.
- Password reset can be requested using email or phone number; reset instructions are sent to the registered email address.
- Admin and customer login pages now use the same SVG logo as the footer.
- Requires Prisma db push because User suspension fields were added to schema.prisma.
